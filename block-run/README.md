# BLOCK RUN

Night-cart arcade backup. Jump to dodge, sell packs at the dumpster, buy guns at the shop, heat calls cops.

Feel pass: same vibe, slower heat/spawns, jump actually clears trouble, you get a few seconds on the block before it goes fubar.

**Play:**

- Grok: https://plum-rapid-kind-fjord.grok.me
- GitHub Pages (once enabled): https://maxrich25.github.io/Steampunk-RPG-Guantlet/

This folder is a local copy of that cart (sprites, map, and game code) so it is not stuck only on Grok.

## Play this copy

Needs a tiny web server (opening the HTML as a raw file may miss sprites).

```bash
cd block-run
python3 -m http.server 8080
```

Then open http://localhost:8080

On a phone, keep using the grok.me link unless you host this folder somewhere.

## Controls

- L / R or A D / arrows — walk
- JUMP or W / up — dodge
- FIRE or space / J — shoot
- Hold FIRE in the SHOP — buy Uzi, then Shotty
- Grab packs, walk to SELL (dumpster) for cash
